# 🧟 KOTA MATI

### Pixel-Art Zombie FPS • Browser Game • Solo & Online Co-op

> **Kota Mati** adalah game FPS zombie bergaya **pixel-art arcade** yang dapat dimainkan langsung melalui browser, baik di **PC maupun HP**.
>
> Bertahan hidup dari gelombang zombie, kumpulkan uang, beli perlengkapan, bantu teman yang terjatuh, dan hadapi **Raja Zombi** setiap lima gelombang.

🎮 **Single Player** · 👥 **Co-op Online** · ⚔️ **PvP** · 🌙 **Night Mode** · 📱 **Mobile Support**

---

## 🎮 Tentang Game

**Kota Mati** dibuat dengan konsep FPS arcade yang sederhana tetapi penuh aksi.

# 🕹️ Game Modes

## 🧟 Solo

Bertahan hidup menghadapi gelombang zombie sebanyak mungkin.

- Gelombang zombie semakin sulit.
- Tersedia sistem **1UP** yang sangat langka.
- Setiap 5 gelombang muncul **Raja Zombi**.
- Tersedia toko di antara gelombang.
- Statistik akhir mencatat kill, headshot, skor, dan akurasi.

## 👥 Co-op Online

Bermain bersama **2–4 pemain**.

- Melawan zombie bersama-sama.
- Pemain yang kehabisan darah akan terjatuh.
- Teman dapat menghidupkan kembali pemain.
- Bisa memberikan tanda lokasi.
- Minimap menampilkan posisi teman dan zombie.
- Jika seluruh pemain terjatuh, permainan berakhir.

## ⚔️ PvP

Mode pertarungan **1 vs 1 selama 5 menit**.

- Pemain dengan kill terbanyak menang.
- Pemain ketiga dan seterusnya menjadi penonton.
- Mendukung stiker ekspresi selama pertandingan.

# 👑 Boss

Setiap **5 gelombang** akan muncul:

## 👑 Raja Zombi

Boss utama Kota Mati.

Kemampuan:

- Menghantam tanah.
- Melempar batu.
- Mengamuk ketika HP berada di bawah 50%.
- Memiliki HP sangat tinggi.

**Tips:** lompat ketika Raja Zombi menghantam tanah untuk menghindari serangan area.

# 🤝 Revive System

Dalam Co-op, pemain yang kehabisan darah tidak langsung mati.

Pemain akan masuk kondisi **Downed**.

- ⏱️ Waktu bertahan sekitar **35 detik**
- 🔫 Masih dapat menggunakan pistol
- 🤝 Teman dapat melakukan revive
- ⏳ Tahan `E` selama **3 detik**
- ❤️ Pemain bangkit dengan **40 HP**

Jika seluruh pemain terjatuh:

> **GAME OVER**

```text
┌──────────────┐
│  Select Mode │

       ↓
┌──────────────┐
│ Create Room  │
│      /       │
│ Join by Code │
└──────┬───────┘
       ↓
┌──────────────┐
│    Lobby     │
```

# 🧩 Technical Overview

| Component           | Implementation            |
| ------------------- | ------------------------- |
| Rendering           | 2D Canvas Raycaster       |
| Internal Resolution | 216px height              |
| Width               | 320–480px mengikuti layar |
| Aim                 | Vertical + Horizontal     |
| Sprite              | Generated via code        |
| Audio               | Web Audio API             |
| Multiplayer         | PeerJS                    |
| Storage             | Browser localStorage      |
| Deployment          | GitHub Pages              |
| Game Format         | Single HTML               |

### Rendering

Game menggunakan **raycaster pada Canvas 2D** dengan resolusi internal rendah untuk mempertahankan karakter visual pixel-art sekaligus menjaga performa.

### Assets

Sprite pemain, zombie, senjata, crate, sticker, dan elemen lainnya dibuat melalui kode tanpa membutuhkan file gambar eksternal.

### Storage

Data berikut disimpan menggunakan `localStorage`:

- Player name
- Skin
- Map
- Records
- Night Mode
- Settings

### Testing

Game telah diuji menggunakan browser headless untuk:

- Solo
- Co-op 2 pemain
- PvP
- Mobile layout

# ⚠️ Known Limitations

> Beberapa fitur masih memiliki batasan karena game berjalan sepenuhnya di browser.

### 🌐 Online Multiplayer

Multiplayer melalui GitHub Pages menggunakan PeerJS dan **belum diuji secara langsung dengan pemain publik dalam skala nyata**.

Pengujian yang tersedia masih berupa simulasi browser otomatis.

### 🖥️ PeerJS

Server publik gratis dapat mengalami:

- overload
- koneksi gagal
- room tidak ditemukan

Jika gagal terhubung, coba beberapa saat kemudian.
