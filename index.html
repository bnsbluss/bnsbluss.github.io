About Me

Saya adalah developer yang banyak mengerjakan tools, server, modding, rekayasa file game, dan otomasi —terutama di ekosistem Point Blank.

Saya lebih suka membangun tool yang benar-benar menyelesaikan masalah daripada sekadar membuat prototype.

Saya tertarik membongkar cara kerja sebuah sistem dari level data/file hingga menjadi tool yang mudah digunakan. Dari format binary seperti .I3S, .I3CHR, .i3Pack, .RSC dan .i3AnimPack, sampai server game, web panel, database, pembayaran, dan watchdog Windows.

Saya mengerjakan project-project ini secara mandiri, dengan sebagian proses pengembangan dibantu oleh AI Claude—terutama saat menghadapi kode, struktur file, algoritma, debugging, atau masalah teknis yang sangat sulit.

AI saya gunakan sebagai partner untuk analisis, eksplorasi solusi, dan memecahkan masalah; proses pengujian, validasi, eksperimen, dan keputusan akhir tetap saya lakukan sendiri.
